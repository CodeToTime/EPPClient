# Contributing to EPPClient

Thank you for your interest in contributing to EPPClient.

By submitting a pull request, commit, or any other contribution to this repository, you agree to the terms described in `CLA.md`.

---

### Existing Files

Do not modify or extend the header of existing files.

In particular:

* Do not add personal copyright lines.
* Do not add additional SPDX entries.
* Do not modify the GPL preamble.

Authorship history is preserved through Git history and the `CREDITS.md` file.

---

### New Files

When creating a new file, you must include the preamble shown above.

Optionally, you may add your own copyright line immediately above the SPDX license identifier, using the following format:

```
SPDX-FileCopyrightText: 2026 Your Name or Legal Entity <contact@email>
```

Example:

```
/*
 * SPDX-FileCopyrightText: 2026 Your Name <your@email.com>
 * 
 * SPDX-License-Identifier: GPL-3.0-or-later
 *
 * This file is part of EPPClient.
 * ...
 */
```

The year must reflect the year of creation of the file.

Adding this line is optional. All contributors are also listed in `CREDITS.md`.

---

## Contributor Recognition

Contributors are acknowledged in `CREDITS.md` to avoid cluttering source file headers while ensuring proper attribution.

---

## Contribution Guidelines

* Keep changes focused and atomic.
* Avoid unrelated refactors in feature pull requests.
* Follow the existing project structure and style.
* Discuss large architectural changes before implementing them.

---

Thank you for helping improve EPPClient.
Every contribution, big or small, makes a difference.
